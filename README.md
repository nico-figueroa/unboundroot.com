## 🌐 About Unbound Root
Unbound Root is a family‑run initiative dedicated to helping individuals and families navigate the digital world with confidence. Our mission is to provide clear, practical, and accessible education on:

* Cybersecurity fundamentals
* Safe digital habits for families
* Responsible technology use
* Online privacy
* Everyday computer literacy

The website serves as a central hub for short lessons, downloadable guides, and personalized assessments designed to empower people in cyberspace — regardless of their technical background.

## 🛠️ Tech Stack
The website is built using lightweight, modern, and maintainable frontend technologies:

* HTML5 for structure
* CSS3 for styling
* Vanilla JavaScript for interactivity
* Native ES Modules for clean separation of concerns
* GitHub Pages for hosting
* Custom domain: https://unboundroot.com

## 📁 Frontend JavaScript Structure
The site’s JavaScript is organized into small ES modules to improve clarity and maintainability.

### Module Overview
* js/main.js  
  Application entry point. Initializes modules on DOMContentLoaded.
* js/cards.js  
  Handles interactive behavior for service/topic cards (expansion, toggles).
* js/forms.js  
  Manages AJAX form submissions for contact and assessment forms.
* js/i18n.js  
  Provides language switching (English and Spanish).

### Notes
* Modules are loaded using <script type="module"> in each page.
* Supported in all modern browsers.
* For broader compatibility, bundling tools like Rollup, Vite, or Webpack can be introduced later.
